## Calculadora CLI

Execute `node src/calculator.js <operação> <número> [número]`. As operações
`addition`, `subtraction`, `multiplication`, `division`, `modulo` e `power`
(ou `exponentiation`) recebem dois operandos; `squareRoot` (ou `sqrt`) recebe
um. Os operandos devem ser números finitos.

```bash
node src/calculator.js modulo 10 3
node src/calculator.js power 2 3
node src/calculator.js sqrt 9
```

Divisão ou módulo por zero e raiz quadrada de número negativo retornam erro.
Para executar os testes, use `node --test src/tests/calculator.test.js`.
